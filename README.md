# Автоматизация отгрузок угля и выгрузка ЕГРЮЛ (Primo RPA)

Проект роботизации процесса обработки отчетов по отгрузкам угля и получения выписок из ЕГРЮЛ.

## Описание процесса

1. **Валидация данных**: сверка названий шахт и марок угля с эталонным файлом `Справочники.xlsx`. Некорректные данные отсеиваются.
2. **Консолидация отчетов**: сбор и объединение данных из файлов отчетов по всем директориям шахт.
3. **Агрегация**: группировка данных по схеме «Шахта — Марка — Вес» с подсчетом итоговых объемов.
4. **Выгрузка из ФНС**: автоматический поиск по ИНН на сайте egrul.nalog.ru, скачивание PDF-выписок и их сохранение в папки соответствующих шахт.

## Требования

- Primo RPA Studio
- Доступ к интернету для обращения к сайту nalog.ru
- Исходные таблицы с отчетами и файл справочников

## Запуск проекта

1. Клонируйте репозиторий:
   git clone https://github.com/dev-va-work/Test-Evraz.git

2. Откройте проект в Primo RPA Studio.
3. Запустите главный процесс `MainProcess.ltw`.

Подробное описание логики и настроек находится в файле `Руководство пользователя и документация Primo RPA.docx`.
