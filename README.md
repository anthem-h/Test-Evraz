# Автоматизация отгрузок угля и выгрузка ЕГРЮЛ (Primo RPA)

Проект роботизации на платформе **Primo RPA** для консолидации отчётов по отгрузкам угля и пакетного получения выписок контрагентов из ЕГРЮЛ.

---

## Архитектура решения

Процесс реализован на базе **State Machine** с двухфазной последовательной обработкой через единый диспетчер:

1. **Фаза Excel**: сбор и валидация файлов отгрузок по шахтам, сверка с эталонными справочниками и построение сводного отчёта.
2. **Фаза Web (ЕГРЮЛ)**: транзакционная выгрузка PDF-выписок с портала ФНС по списку ИНН и их распределение по каталогам шахт.
3. **Управление этапами**: остановка транзакций осуществляется сервисным флагом.

---

## Обработка исключений

- **Бизнес-ошибки (BE)**: контрагент не найден в ЕГРЮЛ или неверный формат данных. Фиксируются в логе со скриншотом в соответствующем каталоге, робот переходит к следующей записи.
- **Системные ошибки (SE)**: сбои сети, недоступность сервиса ФНС. Сохраняется скриншот в каталоге, выполняется перезапуск рабочих процессов и повтор состояния.

---

## Быстрый запуск

1. Склонировать репозиторий:
   ```bash
   git clone https://github.com/developer-va/Test-Evraz.git
   ```
2. Открыть проект в **Primo RPA Studio**.
3. Проверить рабочие пути в `Data/Config.xlsx`.
4. Запустить `Main.ltw`.

> Полное техническое описание решения, схема состояний и реестр переменных приведены в файле **«Техническая документация RPA — Обработка отгрузок и выписок ЕГРЮЛ»**.
