# Primo RPA (REFramework + Excel)

**Автоматизация сверки данных (ЕГРЮЛ / Excel) на базе шаблона Primo (REFramework) с локальным управлением транзакциями через Excel-таблицы.**

---

## 1. Архитектура решения

1. Dispatcher: инициализирует окружение, валидирует входной Excel-справочник (guidePath) и подготавливает локальный набор данных для обработки.
2. Performer 1 (Web / ЕГРЮЛ): выполняет обращение к порталу ФНС (egrul.nalog.ru), осуществляет поиск по ИНН/ОГРН и загружает выписки в рабочий каталог (Downloads\_RPA по умолчанию).
3. Performer 2 (Excel): парсит отчеты, сверяет марки с эталонными данными из справочника и формирует финальный отчет (resultFilePath).

## 2. Особенности реализации (State Machine)

- Источник транзакций: локальный файл Excel. В состоянии Init таблица считывается, а в состоянии Get Transaction Data строки передаются на обработку последовательно по индексу TransactionNumber.
- Управление конфигурацией: все рабочие пути, имена процессов и системные параметры вынесены в Data/Config.xlsx.
- BusinessException: несоответствие данных или отсутствие записи в реестре; транзакция фиксируется в BusinessExPath без повторных попыток.
- SystemException: сбои браузера или сети; автоповтор до 2 раз (MaxRetryNumber = 2). При достижении MaxConsecutiveSystemExceptions = 2 процесс безопасно завершается.

## 3. Быстрый запуск и порядок выполнения

1. Склонировать репозиторий: git clone https://github.com/anthem-h/Test-Evraz.git
2. Проверить и настроить все параметры и константы в Data/Config.xlsx.
3. Проверить соответствие Primo Studio и ее расширения в браузере.
4. Запустить модуль Main.ltw.
5. Получить итоговый результат по пути, указанному в resultFilePath.
